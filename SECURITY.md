# Security policy

prgate is experimental and report-only. It never blocks a merge. Even so, security reports are welcome.

## Report a problem privately

If you find a way to bypass a check, a false block, a way to run code from a pull request, or a way to reach the gate App's key, report it privately. Do not open a public issue.

Use GitHub's "Report a vulnerability" button on the Security tab of [Abubakarjutt/PRGate](https://github.com/Abubakarjutt/PRGate/security/advisories/new).

Please include the steps to reproduce it and the prgate version (`pip show prgate`).

## Scope

prgate is a report-only tool. Reports about the security boundary described in `docs/setup.md` are the most useful.
